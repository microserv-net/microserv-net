# Setup

1. Extract this archive.
2. Create or use your public GitHub profile repository named exactly `microserv-net`.
3. Copy every file in this archive into that repository.
4. Commit and push to `main`.
5. In GitHub repository settings, allow GitHub Actions to have read/write workflow permissions.
6. Run **Generate contribution trace** once from the Actions tab.
7. The workflow publishes animated contribution assets to the `output` branch.

The custom SVG scenes are already included and work without any build step.

## Optional tuning

- Change animation durations inside `assets/*.svg`.
- Replace project text in `README.md` as projects become public.
- Pin third-party actions to commit SHAs before a production/security-sensitive setup.
